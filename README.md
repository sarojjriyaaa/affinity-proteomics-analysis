# Affinity Proteomics Data Analysis

## Overview

Hands-on training project using an Olink/SomaScan-style affinity-proteomics
training dataset.

## Workflow

Protein abundance data
→ QC
→ Normalization
→ Differential analysis
→ FDR correction
→ Volcano plot
→ Pathway interpretation

## Tools

- Python
- Pandas
- SciPy
- Matplotlib

## Key concepts

- NPX-style protein abundance
- Quality control
- Normalization
- Differential protein analysis
- FDR
- Volcano plots
- Pathway interpretation

## Dataset

This repository uses a simulated training dataset for educational purposes.
It is not an actual Olink or SomaScan experiment.
